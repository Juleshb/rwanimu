# RWANIMU Premium Public Website Design System
Reusable foundation for future Manirabizi Fidele projects unless a different style is requested.

## Principles
- Premium, calm, confident, modern; strong whitespace and editorial typography.
- Motion is purposeful: floating brand visual, subtle orbit motion, hover lift, smooth anchors.
- Respect `prefers-reduced-motion`; mobile-first responsive fallback.
- Clean information hierarchy; no visual clutter.
- Public presentation never exposes buying cost, WAC, profit, suppliers or internal stock.

## Visual language
Warm off-white canvas, dark ink typography, vivid growth accent, rounded cards, large Manrope display type and DM Sans body type. Hero uses oversized statement + animated brand composition. Product imagery uses large editorial cards.

## Reuse
Reuse spacing rhythm, typography scale, hero composition, card behavior, responsive breakpoints and motion restraint. Brand colors/content can change per future project.
